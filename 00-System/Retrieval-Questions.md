# Retrieval Questions

The real questions this vault needs to be able to answer — drives whether it
ever needs more structure than plain folders + `CLAUDE.md` + `config.yaml`.
Starting draft, edit freely as real usage clarifies what's actually asked.

- What repos exist for `<project>`, and where do they live on disk?
- What Terraform module pattern did we use for `<resource type>`, and why?
- What's the current state of the `<pipeline-name>` pipeline — working, broken, WIP?
- Have we solved this class of problem before (a specific pipeline failure mode,
  a Terraform state issue, an IAM permission gap)?
- What decision did we make about `<topic>`, and is there an ADR for it?
